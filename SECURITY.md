# Security

## Reporting a vulnerability

Write to contact@alchemia.solutions with the subject "Security". This address is the only channel for
vulnerability reports. Describe what you found, how to
reproduce it and what it could expose. Do not open a public issue for a vulnerability, and do not test
against data or accounts that are not yours.

## What is in scope here

This repository holds documentation and read-only examples. A credential committed by mistake, a link that
leads to something it should not, or an example that sends data somewhere unexpected is in scope.

## What we ask

- Give us reasonable time to answer before you disclose.
- Do not access, change or delete data that is not yours.

We will acknowledge a report, tell you what we found, and credit you if you wish.
