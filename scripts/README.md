# scripts

`gen_numbers.py` writes the figures of `data/numbers.json` into the generated blocks of the root README.
`check_links.py` checks the links of the repository without calling the network.

## How to use

```bash
python scripts/gen_numbers.py            # rewrite the blocks
python scripts/gen_numbers.py --check    # exit 1 if a block differs from the data
python scripts/gen_numbers.py --selftest # prove the check in both directions
python scripts/check_links.py            # relative links, anchors and platform links
python scripts/check_links.py --selftest
```

Python 3, standard library only. The code is Apache-2.0 ([../LICENSE-CODE](../LICENSE-CODE)).

## How the figures in `assets/` were made

The SVG files in `assets/` are generated by a script of the ALCHEMIA brand system, not drawn by hand, and
they are not edited by hand. A change to a figure is a request to the design team, who regenerate the files
from the brand system and replace them. The brand system keeps the factory symbols (gates, machines,
banks) that a later version of the figures can use. This repository does not hold the generator.

## What is not here

No curation code. The ATHANOR pipeline is private and is not in this repository.
