# assets

Figures and symbols for the README and the documents.

| File | What it shows |
|---|---|
| `hero.svg` | The banner at the top of the root README |
| `flow.svg` | The ATHANOR pipeline, stages S1 to S7, ending at the AURORA bank |
| `collection-aurora.svg`, `collection-natural.svg`, `collection-drug.svg`, `collection-bioactivity.svg`, `collection-diversity.svg` | The symbol of each of the five collections |

## How to use

Reference them from Markdown with a relative path and keep the alt text. The files come from the ALCHEMIA
brand system and are generated by a script, never edited by hand. Do not redraw them, recolor them or retype
a name in a font. To change one, ask the design team (see [../scripts/README.md](../scripts/README.md)).
