## How to use

[Repository home](../README.md)

Start with the root [README](../README.md), then open the file that matches your question. Figures come
from `data/numbers.json` and appear in the root README only, with their dates. These documents
describe release 2.0.0, which is in preparation and not published, as read on 2026-11-17. What changed is in
[CHANGELOG.md](../CHANGELOG.md).

## What is not here

No pipeline code, configuration, parameter or threshold, no per-compound data, and no statement about
redistributing data from sources whose licence status is under review.
